# 🤖 Academic Research Agent

An AI-powered research assistant that fetches academic papers from arXiv and generates intelligent analysis using Gemini AI.

---

## 🚀 Features
- Search research papers using arXiv API
- AI-powered summarization using Google Gemini
- Clean Streamlit UI
- Chat-based interaction
- Previous topic memory

---

## 🛠️ Tech Stack
- Python
- Streamlit
- LangChain
- Google Gemini AI
- arXiv API
